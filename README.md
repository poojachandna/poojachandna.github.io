## Running Locally

This is a static website. No build tools or package installation are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/poojachandna/poojachandna.github.io.git
   ```

2. Open the repository folder.
3. Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.

## Deployment

The website is hosted using **GitHub Pages** and is published from this repository.

Changes pushed to the configured publishing branch are reflected on the live portfolio after deployment.
